# 📚 **ÍNDICE GERAL - CURSO JAVASCRIPT TODO LIST**

## 🎯 **Visão Geral**

Curso completo de JavaScript através da criação de um TODO List funcional. **8 aulas de 50 minutos** com progressão lógica do básico ao avançado.

* [ ] Material da aula baixado e testado

* [ ] Console do navegador explicado

### **🎯 Metodologia:**

* **Demonstração (15min)** - Professor mostra conceitos
