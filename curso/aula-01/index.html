Conceitos Fundamentais

Variáveis - Guardando Informações

Variáveis são como caixas que guardam informações. Em JavaScript, usamos let para criar variáveis:

Exemplo Prático
let nome = "Maria";
let idade = 25;
let estudante = true;

console.log("Nome:", nome);
console.log("Idade:", idade);
console.log("É estudante?", estudante);

Tipos de Dados

String Texto
"Olá, mundo!" - Qualquer texto entre aspas
Number Números
42, 3.14, -7 - Inteiros ou decimais
Boolean Verdadeiro/Falso
true, false - Apenas estes dois valores

Funções - Automatizando Tarefas

Funções são blocos de código que fazem tarefas específicas. É como criar um comando personalizado!

Criando Sua Primeira Função
function saudar(nome) {
    return "Olá, " + nome + "! 👋";
}

// Usando a função
let mensagem = saudar("João");
console.log(mensagem);

Console - Sua Ferramenta de Debug

Nível 2 Calculadora Básica

8 min Médio

Objetivo: Criar uma função que faz operações matemáticas.

📝 Complete o código:
💻 Resultado:
Dica:

Use if e else if para verificar a operação. Por exemplo: if (operacao === "soma") { return numero1 + numero2; }

Solução:
function calcular(numero1, numero2, operacao) {
    if (operacao === "soma") {
        return numero1 + numero2;
    } else if (operacao === "subtracao") {
        return numero1 - numero2;
    } else if (operacao === "multiplicacao") {
        return numero1 * numero2;
    } else if (operacao === "divisao") {
        return numero1 / numero2;
    }
}

Nível 3 Validador de Dados

12 min Avançado

Objetivo: Criar um sistema que valida diferentes tipos de dados de entrada.

📝 Desafio Completo:
💻 Resultado:
Dicas:
  • Email: Use includes("@") e includes(".")
  • Idade: Verifique se é número e se está entre 0 e 120
  • Nome: Verifique se não está vazio com length > 0
  • Números: Use typeof idade === "number"
Solução:
function validarEmail(email) {
    return typeof email === "string" &&
           email.includes("@") &&
           email.includes(".");
}

function validarIdade(idade) {
    return typeof idade === "number" &&
           idade >= 0 &&
           idade <= 120;
}

function validarNome(nome) {
    return typeof nome === "string" &&
           nome.length > 0;
}
