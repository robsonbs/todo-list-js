Aula 1: Fundamentos e Estrutura

Primeiros passos no mundo do JavaScript

O que aprenderemos hoje:

  • O que é JavaScript e para que serve

Exercício 1: Variáveis Básicas

Abra o console do navegador (F12) e teste estes códigos:

let nome = "Seu Nome Aqui";
let idade = 25;
let estudante = true;
console.log("Olá, " + nome + "!");

Exercício 2: Primeira Função

Copie este código no console:

function saudar(nome) {
  return "Olá, " + nome + "! Bem-vindo ao JavaScript!";
}

// Teste a função
console.log(saudar("Maria"));
