# 🎯 **EXERCÍCIOS PROGRESSIVOS - CURSO JAVASCRIPT**

## 📚 **Exercícios por Aula**

### **🎓 Aula 1: Fundamentos JavaScript**

#### **🥉 Nível Iniciante:**

1. **Variáveis Básicas:** Criar variáveis para nome, idade e hobbies
2. **Primeira Função:** Função que retorna uma saudação personalizada
3. **Operações Matemáticas:** Calculadora com 4 operações básicas
4. **Arrays Simples:** Lista de tarefas com push() e length

#### **🥈 Nível Intermediário:**

1. **Objeto Complexo:** Criar objeto "pessoa" com métodos
2. **Loops e Condicionais:** Iterar sobre array com diferentes condições
3. **Validação:** Função para validar dados de entrada

#### **🥇 Nível Avançado:**

1. **Sistema de Notas:** Calculadora de média com aprovação/reprovação
2. **Manipulação de Strings:** Parser de texto com contagem de palavras

---

### **🎓 Aula 2: DOM e Primeiras Interações**

#### **🥉 Nível Iniciante:**

1. **Seletores Básicos:** getElementById, querySelector
2. **Modificar Conteúdo:** textContent e innerHTML
3. **Alterar Estilos:** style.color, classList.add/remove
4. **Primeiro Evento:** Click em botão para mostrar alerta

#### **🥈 Nível Intermediário:**

1. **Formulário Simples:** Capturar valor de input e exibir
2. **Toggle de Visibilidade:** Mostrar/ocultar elementos
3. **Mudança de Temas:** Alternar entre modo claro/escuro

#### **🥇 Nível Avançado:**

1. **Validação em Tempo Real:** Feedback visual conforme usuário digita
2. **Componente Reutilizável:** Função para criar cards dinâmicos

---

### **🎓 Aula 3: Eventos e Interatividade**

#### **🥉 Nível Iniciante:**

1. **Eventos Básicos:** click, keypress, submit
2. **preventDefault():** Prevenir comportamento padrão
3. **Event Object:** Acessar propriedades do evento
4. **Input Validation:** Verificar se campo não está vazio

#### **🥈 Nível Intermediário:**

1. **Múltiplos Eventos:** Mesmo elemento com vários listeners
2. **Event Delegation:** Escutar eventos em elementos dinâmicos
3. **Keyboard Navigation:** Navegação por teclas (Enter, Escape)

#### **🥇 Nível Avançado:**

1. **Custom Events:** Criar e disparar eventos customizados
2. **Debouncing:** Limitar frequência de execução de função
3. **Drag and Drop:** Implementar arrastar e soltar básico

---

### **🎓 Aula 4: Arrays e Manipulação de Dados**

#### **🥉 Nível Iniciante:**

1. **CRUD Básico:** push(), splice(), find(), filter()
2. **Iteração:** forEach() e map()
3. **Busca:** indexOf() e includes()
4. **Ordenação:** sort() com strings e números

#### **🥈 Nível Intermediário:**

1. **Métodos Avançados:** reduce(), some(), every()
2. **Objetos em Arrays:** Manipular arrays de objetos
3. **Filtragem Complexa:** Múltiplos critérios
4. **Agrupamento:** Agrupar elementos por propriedade

#### **🥇 Nível Avançado:**

1. **Performance:** Comparar diferentes abordagens
2. **Estruturas Complexas:** Arrays multidimensionais
3. **Algoritmos:** Implementar busca binária simples

---

### **🎓 Aula 5: Criação Dinâmica de Elementos**

#### **🥉 Nível Iniciante:**

1. **createElement():** Criar elementos básicos
2. **appendChild():** Inserir elementos na página
3. **setAttribute():** Definir atributos dinâmicos
4. **Template Simples:** Criar card de tarefa

#### **🥈 Nível Intermediário:**

1. **innerHTML vs createElement:** Comparar abordagens
2. **Document Fragments:** Otimizar inserções múltiplas
3. **Clonagem:** cloneNode() para templates
4. **Componentes:** Funções que retornam elementos

#### **🥇 Nível Avançado:**

1. **Virtual DOM Simples:** Sistema de diff básico
2. **Template Engine:** Parser de templates próprio
3. **Web Components:** Custom elements básicos

---

### **🎓 Aula 6: Eventos Avançados e Funcionalidades**

#### **🥉 Nível Iniciante:**

1. **Event Bubbling:** Entender propagação de eventos
2. **stopPropagation():** Controlar propagação
3. **Checkbox Events:** change, input
4. **Form Validation:** Validar antes de submeter

#### **🥈 Nível Intermediário:**

1. **Event Delegation Avançado:** Múltiplos tipos de evento
2. **Touch Events:** Suporte a dispositivos móveis
3. **Intersection Observer:** Detectar elementos visíveis
4. **Mutation Observer:** Observar mudanças no DOM

#### **🥇 Nível Avançado:**

1. **Performance:** Throttling de eventos de scroll
2. **Gesture Recognition:** Detectar gestos básicos
3. **Keyboard Shortcuts:** Sistema de atalhos

---

### **🎓 Aula 7: LocalStorage e Persistência**

#### **🥉 Nível Iniciante:**

1. **Básicos:** setItem(), getItem(), removeItem()
2. **JSON:** stringify() e parse()
3. **Verificação:** Existência de dados
4. **Limpar:** clear() e gestão de espaço

#### **🥈 Nível Intermediário:**

1. **Backup/Restore:** Exportar/importar dados
2. **Sincronização:** Múltiplas abas
3. **Storage Events:** Reagir a mudanças
4. **Fallbacks:** Comportamento sem localStorage

#### **🥇 Nível Avançado:**

1. **IndexedDB:** Banco de dados cliente
2. **Service Workers:** Cache offline
3. **Compression:** Comprimir dados para economizar espaço

---

### **🎓 Aula 8: Funcionalidades Avançadas**

#### **🥉 Nível Iniciante:**

1. **Edição Inline:** Double-click para editar
2. **Confirmações:** confirm() antes de deletar
3. **Contadores:** Calcular estatísticas
4. **Animações CSS:** Transições básicas

#### **🥈 Nível Intermediário:**

1. **Drag and Drop:** Reordenar tarefas
2. **Filtros:** Mostrar por status
3. **Busca:** Filtrar por texto
4. **Temas:** Sistema de cores

#### **🥇 Nível Avançado:**

1. **PWA:** Progressive Web App básica
2. **Offline:** Funcionamento sem internet
3. **Push Notifications:** Notificações do sistema
4. **Web Workers:** Processamento em background
