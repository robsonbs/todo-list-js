Objetivos de Aprendizagem
🎯 Ao final desta aula você será capaz de:
  • Entender LocalStorage vs SessionStorage
  • Salvar e recuperar dados do navegador
  • Trabalhar com objetos JSON no storage
  • Criar sistemas de configurações
🛠️ Tecnologias utilizadas:
localStorage sessionStorage JSON JavaScript ES6+ Storage Events

Demonstração 1: Conceitos Básicos de Storage

Aprenda a diferença entre LocalStorage e SessionStorage, e como usar os métodos básicos para armazenar dados.

Demonstração 2: Trabalhando com Objetos JSON

Descubra como serializar e deserializar objetos JavaScript para armazenamento persistente no navegador.

Demonstração 3: Sistema de Configurações

Crie um sistema completo de preferências do usuário com persistência automática e exportação/importação.

Demonstração 4: TODO List Persistente

Implemente um sistema completo de TODO List que mantém os dados mesmo após fechar o navegador.

Demonstração 5: Analytics e Storage Events

Monitore o uso do storage, implemente analytics e reaja a mudanças em tempo real.

Referência Rápida: Métodos de Storage
📝 Métodos Básicos
localStorage.setItem('chave', 'valor');
localStorage.getItem('chave');
localStorage.removeItem('chave');
localStorage.clear();
🔄 Trabalhando com JSON
// Salvar objeto
localStorage.setItem('obj', JSON.stringify(data));
// Recuperar objeto
const data = JSON.parse(localStorage.getItem('obj'));
