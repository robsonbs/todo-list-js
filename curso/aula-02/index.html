📚 1. O que é DOM?

DOM significa Document Object Model (Modelo de Objeto do Documento).

É como o JavaScript "enxerga" e manipula o HTML da página.

💡 Analogia: Se o HTML é uma árvore genealógica, o DOM é como você navega entre os parentes: pais, filhos, irmãos!

🌳 Visualização da Árvore DOM

document
└── html
    ├── head
    │   └── title
    └── body
        ├── h1
        ├── p
        └── div

🎯 2. Selecionando Elementos

Antes de modificar elementos, precisamos "pegá-los" primeiro!

// 1. Por ID (único) const titulo = document.getElementById("meu-titulo"); // 2. Por classe (pode ter vários) const botoes = document.getElementsByClassName("botao"); // 3. Seletor CSS moderno (recomendado) const botao = document.querySelector("#meu-botao"); const todosBotoes = document.querySelectorAll(".botao");

✏️ 3. Modificando Conteúdo

Agora vamos mudar o que está escrito nos elementos!

// Mudando texto simples elemento.textContent = "Novo texto aqui"; // Mudando HTML (com tags) elemento.innerHTML = "<strong>Texto em negrito</strong>"; // Mudando atributos elemento.setAttribute("class", "nova-classe"); elemento.id = "novo-id";

🔄 Texto que vai mudar

Este parágrafo será modificado!

🎨 4. Modificando Estilos

Vamos dar uma nova aparência aos elementos!

// Mudando estilos diretamente elemento.style.color = "red"; elemento.style.backgroundColor = "yellow"; elemento.style.fontSize = "20px"; // Trabalhando com classes CSS (recomendado) elemento.classList.add("destaque"); elemento.classList.remove("antigo"); elemento.classList.toggle("ativo");
🎨 Caixa para Modificar Estilos

🖱️ 5. Primeiro Evento

Vamos fazer a página reagir aos cliques do usuário!

// Forma básica (não recomendada) botao.onclick = function() { alert("Clicou!"); }; // Forma moderna (recomendada) botao.addEventListener("click", function() { console.log("Botão clicado!"); });
