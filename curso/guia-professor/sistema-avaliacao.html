Sistema de Avaliação

Ferramentas e critérios para avaliar o progresso dos alunos de forma justa e abrangente

Filosofia de Avaliação

O sistema de avaliação do curso JavaScript segue uma abordagem formativa e inclusiva, focando no progresso individual e no desenvolvimento de competências práticas.

Princípios Fundamentais
  • Avaliação Contínua: Múltiplos pontos de verificação
  • Feedback Construtivo: Orientação para melhoria
  • Transparência: Critérios claros e conhecidos
  • Inclusividade: Respeito às diferenças individuais
Foco nas Competências
  • Pensamento computacional
  • Resolução de problemas
  • Sintaxe e semântica JavaScript
  • Trabalho colaborativo
  • Comunicação técnica

Distribuição da Nota
Projetos (40%)
Exercícios (30%)
Participação (20%)
Avaliações (10%)

Tipos de Avaliação

Diferentes modalidades para capturar o aprendizado de forma abrangente

Avaliação Formativa

Contínua

Objetivo: Monitorar o progresso e fornecer feedback para melhoria.

Instrumentos:
  • Observação durante exercícios
  • Análise de código produzido
  • Participação em discussões
  • Autoavaliação dos alunos
  • Peer review (avaliação por pares)
Frequência:

A cada aula, durante todas as atividades práticas.

Avaliação Somativa

Periódica

Objetivo: Verificar o domínio de competências ao final de módulos.

Instrumentos:
  • Projetos práticos individuais
  • Projetos em grupo
  • Quizzes e testes conceituais
  • Apresentações técnicas
  • Portfolio de trabalhos
Frequência:

Ao final de cada módulo (3-4 vezes no curso).

Avaliação Diagnóstica

Inicial

Objetivo: Identificar conhecimentos prévios e necessidades específicas.

Instrumentos:
  • Questionário inicial de conhecimentos
  • Teste de lógica básica
  • Entrevista informal
  • Autoavaliação de experiência
Frequência:

Início do curso e início de novos módulos.

Avaliação Adaptativa

Personalizada

Objetivo: Adaptar o nível de dificuldade conforme o progresso individual.

Instrumentos:
  • Exercícios com níveis progressivos
  • Desafios opcionais avançados
  • Projetos com complexidade variável
  • Trilhas de aprendizado personalizadas
Frequência:

Conforme necessidade e ritmo individual.

Rubricas de Avaliação

Critérios específicos para avaliação justa e consistente

Rubrica Geral - Competências JavaScript

Critério Excelente (4) Proficiente (3) Em Desenvolvimento (2) Iniciante (1)
Sintaxe e Estrutura Código sem erros sintáticos, estrutura clara e bem organizada Poucos erros sintáticos, estrutura adequada Alguns erros sintáticos, estrutura básica Muitos erros sintáticos, estrutura confusa
Lógica de Programação Lógica complexa implementada corretamente, soluções eficientes Lógica adequada, soluções funcionais Lógica básica, algumas inconsistências Lógica simples, muitas inconsistências
Uso de Variáveis Uso correto de let/const, nomes descritivos, escopo adequado Uso adequado de variáveis, nomes razoáveis Uso básico de variáveis, alguns problemas de escopo Uso inconsistente, problemas de nomenclatura
Funções Funções bem estruturadas, reutilizáveis, com parâmetros apropriados Funções funcionais, estrutura adequada Funções básicas, alguns problemas de implementação Dificuldade com conceito de funções
Manipulação de Arrays Uso avançado de métodos de array, implementações eficientes Uso adequado de métodos básicos Uso básico de arrays, alguns métodos Dificuldade com conceitos de array
Objetos e JSON Manipulação avançada de objetos, uso de destructuring Criação e manipulação básica de objetos Conceitos básicos de objetos Dificuldade com objetos
DOM e Eventos Manipulação avançada do DOM, múltiplos tipos de eventos Manipulação básica do DOM, eventos simples Seleção de elementos, eventos básicos Dificuldade com conceitos de DOM
Debugging e Testes Uso eficiente de ferramentas de debug, testes básicos Uso de console.log e ferramentas básicas Identificação de erros simples Dificuldade para identificar erros

Rubrica Específica - Projetos

Aspecto Excelente (4) Proficiente (3) Em Desenvolvimento (2) Iniciante (1)
Funcionalidade Todas as funcionalidades implementadas perfeitamente Principais funcionalidades implementadas Funcionalidades básicas implementadas Poucas funcionalidades funcionando
Interface do Usuário Interface intuitiva, design atrativo, responsiva Interface clara e funcional Interface básica, alguns problemas Interface confusa ou mal estruturada
Qualidade do Código Código limpo, bem comentado, estruturado Código organizado, comentários adequados Código funcional, organização básica Código desorganizado, poucos comentários
Criatividade Soluções inovadoras, funcionalidades extras Algumas soluções criativas Implementação padrão com pequenas variações Implementação básica sem personalização
Documentação Documentação completa, README detalhado Documentação adequada Documentação básica Pouca ou nenhuma documentação
