Guias completos para cada aula do Curso JavaScript Interativo

Aula 1: Introdução ao JavaScript

Duração: 2 horas Nível: Iniciante
Objetivos de Aprendizagem
  • Compreender o que é JavaScript e sua importância
  • Conhecer a história e evolução da linguagem
  • Configurar ambiente de desenvolvimento
  • Escrever e executar o primeiro programa
  • Entender conceitos básicos: console, comentários, estrutura
Cronograma (120 min)
0-15 min: Apresentação e motivação
15-30 min: História do JavaScript
30-60 min: Setup do ambiente
60-90 min: Primeiro programa
90-110 min: Exercícios práticos
110-120 min: Síntese e preview
Atividades Práticas
1. Hello World Interativo

Criar primeiro programa que exibe mensagem no console e na tela

15 min
2. Calculadora de Idade

Programa que calcula idade com base no ano de nascimento

20 min
3. Gerador de Mensagens

Sistema que exibe mensagens aleatórias motivacionais

25 min
Recursos Necessários
  • Computador com navegador atualizado
  • Editor de código (VS Code recomendado)
  • Acesso à internet
  • Slides de apresentação
  • Exemplos de código inicial
Avaliação

Formativa: Observação durante exercícios

Sumativa: Quiz sobre conceitos básicos (10 questões)

Projeto: Página pessoal com JavaScript básico

Tarefa de Casa

Criar uma página HTML simples com JavaScript que:

  • Exiba uma mensagem de boas-vindas
  • Mostre a data/hora atual
  • Tenha pelo menos 3 comentários explicativos
Dicas para o Professor
  • Começar com exemplos visuais e práticos
  • Usar analogias do mundo real
  • Incentivar experimentação
  • Ter templates prontos para economizar tempo

Aula 2: Variáveis e Tipos de Dados

Duração: 2 horas Nível: Iniciante
Objetivos de Aprendizagem
  • Declarar variáveis usando let, const e var
  • Identificar e trabalhar com tipos primitivos
  • Realizar conversões entre tipos
  • Aplicar operadores aritméticos e lógicos
  • Entender escopo de variáveis
Conceitos-Chave
Declaração de Variáveis
let, const, var
Tipos Primitivos
string, number, boolean, undefined, null
Operadores
+, -, *, /, %, ==, ===, &&, ||
Atividades Práticas
1. Declaração e Uso de Variáveis

Exercícios progressivos de declaração e manipulação

20 min
2. Calculadora de IMC

Aplicação prática com entrada, cálculo e saída

30 min
3. Jogo de Adivinhação

Programa interativo com comparações e lógica

25 min
Erros Comuns
  • Confundir == com ===
  • Não declarar variáveis (usar sem let/const)
  • Tentar reatribuir constantes
  • Problemas de escopo

Aula 3: Funções

Duração: 2 horas Nível: Iniciante-Intermediário
Objetivos de Aprendizagem
  • Criar e chamar funções
  • Usar parâmetros e argumentos
  • Implementar return em funções
  • Entender escopo de funções
  • Aplicar arrow functions
Estratégias de Ensino
  • Analogia: Funções como "máquinas"
  • Demonstração visual com exemplos práticos
  • Construção progressiva de complexidade
  • Pair programming para resolução
Projetos da Aula
1. Biblioteca Matemática

Criar funções para operações matemáticas básicas

25 min
2. Validador de Formulários

Funções para validar email, telefone, senha

35 min
3. Conversor de Unidades

Sistema modular de conversões com funções

30 min

Aula 4: Arrays e Métodos

Duração: 2.5 horas Nível: Intermediário
Objetivos de Aprendizagem
  • Criar e manipular arrays
  • Usar métodos essenciais (push, pop, map, filter)
  • Implementar loops para iteração
  • Trabalhar com arrays multidimensionais
  • Aplicar conceitos em projetos práticos
Métodos em Foco
push() - Adicionar elementos
map() - Transformar elementos
filter() - Filtrar elementos
reduce() - Reduzir array
Projetos Práticos
1. Lista de Compras Inteligente

CRUD completo com arrays e métodos

40 min
2. Sistema de Notas

Calculadora de médias com estatísticas

35 min
3. Agenda de Contatos

Gerenciamento completo com busca e filtros

45 min

Aula 5: Objetos e JSON

Duração: 3 horas Nível: Intermediário
Objetivos de Aprendizagem
  • Criar e manipular objetos
  • Acessar propriedades e métodos
  • Trabalhar com JSON
  • Implementar objetos aninhados
  • Usar destructuring e spread operator
Conceitos Avançados
  • Object.keys(), Object.values()
  • JSON.parse() e JSON.stringify()
  • Destructuring assignment
  • Spread operator (...)
  • Optional chaining (?.)
Projetos Avançados
1. Sistema de Usuários

CRUD com objetos complexos e validação

50 min
2. E-commerce Básico

Carrinho de compras com produtos e cálculos

60 min
3. API de Biblioteca

Sistema de livros com busca e categorização

50 min
